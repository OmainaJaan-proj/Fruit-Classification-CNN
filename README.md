# Fruit-Classification-CNN
Deep Learning project for fruit image classification using Tensor Flow and CNN.

# 🍎 Fruit Recognition using Convolutional Neural Network (CNN)

## 📌 Project Overview
This project implements a Convolutional Neural Network (CNN) using TensorFlow and Keras to classify fruit images into 33 different categories. The model was trained and evaluated on a Kaggle image dataset using Google Colab.

## 🚀 Features
- Image Classification using CNN
- 33 Fruit Classes
- Data Preprocessing
- Model Training & Validation
- Accuracy and Loss Visualization
- Saved Trained Model (.keras)

## 🛠️ Technologies Used
- Python
- TensorFlow
- Keras
- Google Colab
- NumPy
- Matplotlib

## 📂 Dataset
https://www.kaggle.com/datasets/sshikamaru/fruit-recognition
